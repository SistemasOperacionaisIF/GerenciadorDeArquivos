# Gerenciador de Arquivos

## Objetivo
Simular um Gerenciador de Arquivos em python.

## Comandos
- ls = Listar Conteudos do diretório
- cd = Mudar Diretorio
- mkdir = Criar Diretorio
- touch = Criar Arquivo
- rm = deletar
- exit = Para código.
